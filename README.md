## 📱 About The Project

**Asaan Optics** is a comprehensive, SaaS-based mobile application designed specifically for opticians, eye clinics, and eyewear retail stores in Pakistan and beyond. It eliminates the need for manual registers by digitizing the entire workflow—from customer eye prescriptions to inventory management, sales tracking, and seamless WhatsApp digital receipts.

> **Note:** This repository serves as a **Product Showcase & Portfolio Piece**. The proprietary source code is closed-source.

## 🛠️ Technical Highlights

As a Digital Solutions Provider, I focused on building a scalable, secure, and user-friendly architecture:

* **Robust Database:** Secure local and cloud data synchronization ensuring no data loss.
* **Payment Integration:** Seamless integration with Easypaisa for automated subscription handling.
* **PDF & Invoice Generation:** Dynamic rendering of professional invoices optimized for mobile viewing and thermal printing.
* **Cross-Device Sync:** Seamlessly connects with the **Asaan Optics Desktop Pro** version for a complete retail ecosystem.
